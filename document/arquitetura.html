Fluxo de UI

HomePage
  ├─ Dropdown de versões (json/index.json)
  └─ Lista de testamentos
       ├─ Velho Testamento → TestamentBooksPage → ChaptersPage → VersesPage
       └─ Novo Testamento  → TestamentBooksPage → ChaptersPage → VersesPage

Camada de dados (BibleRepository)

  • listVersions() carrega json/index.json e monta a lista de versões.
  • listBooks(version) carrega json/<version>.json e monta BibleBookRef com nome/abbrev e quantidade de capítulos.
  • loadChapter(version, bookIndex, chapterIndex) lê apenas o capítulo solicitado e devolve uma lista de strings (versículos).

O repositório usa cache: uma vez que a versão foi carregada, ela fica em memória para evitar reler o asset a cada navegação.

Por que existe _JsonScanner?

Os arquivos json/<versão>.json podem ser grandes. Decodificar o JSON inteiro com json.decode para só pegar um livro/capítulo pode ser custoso.

O _JsonScanner faz uma varredura de string para:

  • achar os spans (início/fim) dos livros no array do topo;
  • encontrar o campo chapters do livro;
  • pegar o N-ésimo capítulo do array de capítulos;
  • decodificar apenas aquele trecho pequeno com json.decode.

Regra de Velho/Novo Testamento

A separação é feita por índice: os 39 primeiros livros (índices 0–38) são Velho Testamento e o restante é Novo Testamento. Isso funciona porque os arquivos JSON estão em ordem canônica.

Bug corrigido: “todo livro tem 1 capítulo”

A contagem de itens do array chapters estava incorreta e só reconhecia o primeiro item. A correção ajustou a função que conta itens de um array no nível 1, incluindo itens que começam com " (strings), números e outros valores, e reinicia a leitura ao encontrar vírgulas.
