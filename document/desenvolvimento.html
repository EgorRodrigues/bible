Comandos úteis

flutter run

Testes

  • O teste principal é test/widget_test.dart.
  • Ele usa um AssetBundle fake para isolar a UI e validar o fluxo sem depender dos arquivos reais em json/.

Pontos de atenção

  • Arquivos grandes: carregar um JSON inteiro pode ser pesado; por isso existe o scanner que lê trechos.
  • Ordem dos livros: a separação Velho/Novo assume que o JSON está em ordem canônica.
  • Erros de parsing: se algum arquivo JSON estiver malformado, o app vai falhar ao listar livros/capítulos daquela versão.

Próximos passos típicos (se você quiser)

  • Extrair BibleRepository e _JsonScanner para arquivos separados em lib/.
  • Adicionar busca (livro/capítulo/verso ou texto).
  • Adicionar favoritos e histórico (persistência local).
