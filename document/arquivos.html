Arquivos principais

Onde está o que importa no projeto

Início Arquivos principais Arquitetura e fluxo Dados (JSON/XML) Desenvolvimento

lib/

lib/main.dart

  • Ponto de entrada do app (main()).
  • Configura handlers de erro (FlutterError.onError e PlatformDispatcher.instance.onError).
  • Sobe o widget raiz (BibleStudyApp → BibleApp).

lib/bible_app.dart

  • UI inteira do app (Home, lista de testamentos, livros, capítulos e versículos).
  • BibleRepository: carrega assets em json/ e entrega versões/livros/capítulos.
  • _JsonScanner: parser “rápido” baseado em string para localizar trechos no JSON sem decodificar o arquivo inteiro de uma vez.
  • Regras de navegação: Home → Testamento → Livro → Capítulo.

json/

  • json/index.json: índice de idiomas e versões (nome + abreviação).
  • json/<abbreviation>.json: conteúdo da Bíblia (array de livros com chapters).
  • É o “backend” do app hoje: tudo é carregado via AssetBundle.

xml/

  • Fontes em XML equivalentes às versões de json/.
  • No app atual, os XML não são consumidos diretamente (somente o JSON).

test/

test/widget_test.dart

  • Teste de widget que valida o fluxo básico: carregar livros, abrir testamento, abrir livro, abrir capítulos.
  • Usa um AssetBundle fake para simular os assets json/index.json e json/pt_nvi.json.

pubspec.yaml

  • Declara dependências e assets do Flutter.
  • Inclui a pasta json/ como assets do app, permitindo rootBundle.loadString(...).
