Dados (JSON/XML)

Como os arquivos estão estruturados e como adicionar uma versão

Início Arquivos principais Arquitetura e fluxo Dados (JSON/XML) Desenvolvimento

Índice de versões: json/index.json

O app lista as versões a partir deste arquivo. O formato é:

[
  {
    "language": "Portuguese",
    "versions": [
      { "name": "Nova Versão Internacional", "abbreviation": "pt_nvi" }
    ]
  }
]

O campo abbreviation precisa bater com o nome do arquivo em json/ (ex.: json/pt_nvi.json).

Conteúdo da Bíblia: json/<versão>.json

Formato esperado pelo app:

[
  {
    "abbrev": "gn",
    "name": "Gênesis",
    "chapters": [
      ["Verso 1", "Verso 2"],
      ["Verso 1", "Verso 2"]
    ]
  }
]
  • O arquivo é um array de livros.
  • Cada livro tem chapters como array de capítulos.
  • Cada capítulo é um array de strings (versículos).

XML

Existe também uma pasta xml/ com a mesma Bíblia em formato XML, mas o app atual não consome esses arquivos.

<book>
  <chapter>
    <verse>Texto</verse>
  </chapter>
</book>

Como adicionar uma versão

  1. Coloque o arquivo em json/<sua_abrev>.json.
  2. Adicione a entrada em json/index.json (idioma, nome e abreviação).
  3. Garanta que pubspec.yaml continua incluindo json/ em assets.
  4. Rode o app e selecione a nova versão no dropdown.
