Visão geral

Este app Flutter carrega versões da Bíblia a partir de arquivos JSON em assets e navega em três níveis:

  1. Seleção de versão
  2. Seleção de testamento (Velho/Novo)
  3. Seleção de livro → capítulo → versículos

A lógica do app está concentrada em um arquivo principal (UI + repositório + parser) para simplificar, mas dá para modularizar depois se quiser.

Mapa do projeto

bible/

    main.dart
    bible_app.dart
  json/
    index.json

As pastas android/, ios/, macos/ e web/ são geradas/gerenciadas pelo Flutter para cada plataforma.
